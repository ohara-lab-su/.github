# 島根大学 尾原研究室 | Ohara Lab

[研究室HP](https://ohara.mat.shimane-u.ac.jp/) / [Documentation](https://ohara-lab-su.github.io/) / [PyPI](https://pypi.org/user/ohara-lab/)

島根大学 尾原研究室で開発している、実験装置制御・ラボオートメーションおよび材料の構造解析・モデリングに関するソフトウェアを公開しています。

主な開発対象は以下のとおりです。

- **実験装置制御・ラボオートメーション**  
  ロボットや計測機器の制御ライブラリ、デバイスサーバー、通信フレームワーク、実験自動化のためのツール
- **構造解析・計算科学**  
  非晶質材料を中心とした構造解析・モデリングを支援するツール。逆モンテカルロ法（RMC）、機械学習ポテンシャル（MLP）、第一原理計算（DFT）などを活用

装置制御では、機器固有の制御機能を通信方式や上位システムから分離し、既存のソフトウェア資産を再利用できる構成を基本としています。

ソフトウェアの一覧、設計方針、使用方法、APIドキュメントなどは [GitHub Pages](https://ohara-lab-su.github.io/) を参照してください。

---

Software developed at Ohara Lab, Shimane University, for experimental instrumentation, laboratory automation, and materials structure analysis and modeling.

Our projects include:

- **Experimental instrumentation and laboratory automation**  
  Device control libraries, device servers, communication frameworks, and tools for laboratory automation.
- **Structural analysis and computational modeling**  
  Tools for structural analysis and modeling of materials, with an emphasis on amorphous systems, using methods such as Reverse Monte Carlo (RMC), machine learning potentials (MLP), and density functional theory (DFT).

For project information and technical documentation, visit our [GitHub Pages](https://ohara-lab-su.github.io/).
